# 📞 Sheets to Voice Dialer (Google Sheets Extension)

A lightweight browser extension that allows users to click on a phone number inside Google Sheets and automatically dial it using Google Voice.

---

## 🚀 Features

- Click any cell containing a phone number in Google Sheets
- Instantly send the number to Google Voice dialer
- Fast one-click calling workflow
- Works directly inside Google Sheets interface
- Simple and lightweight extension (no backend required)

---

## 🧠 How It Works

1. User opens a Google Sheet
2. Selects or clicks a cell containing a phone number
3. The extension detects the selected value
4. It automatically triggers Google Voice dial action with that number
